# Snack Man

A Pac-Man style browser game written in plain JavaScript, HTML and CSS for a university assignment.

## Features

- Maze built from a 2D array and drawn into a CSS grid
- Player movement with the arrow keys, locked until the Start button is pressed
- Wall collision detection using the player's bounding box
- Score counter that goes up as points are eaten, with a win message at 50 points
- Enemies that trigger a death animation and a game over message on contact
- Animated mouth that faces the direction of travel

## Running it

Open `index.html` in any modern browser. No build step or server is needed.

## Tech

JavaScript, HTML, CSS (grid layout, keyframe animations, clip-path)
